# Integrated research contract

One ticker search requests a fresh Python analysis. It then requests actual OpenBB provider statement fetchers and a VectorBT simulation on that ticker's newly fetched completed daily bars. These requests are separate so statement-provider failures cannot blank price analysis. Results retain original calculation and source times when reused from cache.

Qlib fits only in GitHub Actions, never in HTTP requests. The scheduled experiment uses fixed ridge parameters and expanding held-out blocks, then saves model coefficients and an explicitly experimental next-session forecast. Immutable research records are committed to GitHub. This is not a calibrated probability, executable return or validated production model. Scheduled coverage is NVDA, GOOG, RY.TO and AAPL; other tickers do not inherit their models.

LEAN runs an actual official Docker engine on GitHub Actions, using source OHLC observations encoded as separate open/close events. It has no network or brokerage access during simulation. Its own fees and slippage are explicit. Only a successfully completed output with actual input observations is published. The initial experiment covers NVDA only.

TradingAgents runs the actual pinned upstream graph on GitHub Actions with a free local Ollama model. Only a completed market/fundamental analyst and debate/risk pipeline is published. Its opinions are unverified, retained in an audit archive and never promoted to a verified trade instruction. A small model and limited tool rounds constrain quality. Initial coverage is NVDA only.

All framework statuses describe completed executions, not imports or adapter code. An installed package without a successful run remains unavailable. Combining engines does not produce an accuracy percentage or a confidence vote. The primary quote remains an unofficial provider-reported minute bar; exchange entitlement and independent price confirmation remain unverified.

Public on-demand forecasts are not durably recorded. Scheduled Qlib forecast records are durable; full live forward evaluation and durable arbitrary-ticker forecast collection remain unfinished. This gap must remain visible and must not be described as demonstrated accuracy.
