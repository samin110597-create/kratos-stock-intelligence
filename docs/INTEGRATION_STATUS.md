# Integrated research contract

One ticker search requests a fresh Python analysis. It then requests actual OpenBB provider statement fetchers and a VectorBT simulation on that ticker's newly fetched completed daily bars. These requests are separate so statement-provider failures cannot blank price analysis. Results retain original calculation and source times when reused from cache.

Qlib fits only in GitHub Actions, never in HTTP requests. The scheduled experiment uses fixed ridge parameters and expanding held-out blocks, then saves model coefficients and an explicitly experimental next-session forecast. Immutable research records are committed to GitHub. This is not a calibrated probability, executable return or validated production model. Scheduled coverage is NVDA, GOOG, RY.TO, AAPL, MSFT, AMZN, META, AVGO, AMD, MU, AMAT, LRCX, IREN and CIFR; additional supported tickers receive their own model runs when a visitor presses Analyze.

LEAN runs an actual official Docker engine on GitHub Actions, using source OHLC observations encoded as separate open/close events. It has no network or brokerage access during simulation. Its own fees and slippage are explicit. Only a successfully completed output with actual input observations is published. The requested worker uses the symbol from the saved request when preparing every simulation.

TradingAgents runs the actual pinned upstream graph on GitHub Actions with a free local Ollama model. Only a completed market/fundamental analyst and debate/risk pipeline is published. Its opinions are unverified, retained in an audit archive and never promoted to a verified trade instruction. A small model and limited tool rounds constrain quality. Each requested run passes the selected symbol to the upstream graph.

All framework statuses describe completed executions, not imports or adapter code. An installed package without a successful run remains unavailable. Combining engines does not produce an accuracy percentage or a confidence vote. The primary quote remains an unofficial provider-reported minute bar; exchange entitlement and independent price confirmation remain unverified.

Pressing Analyze on a successful strict market-data check submits the ticker and latest completed session to a bounded Space inbox. GitHub Actions is scheduled to collect requests twice an hour. Until collection, a Space restart can lose a staged request. Each engine processes its oldest eligible request per run, so backlogs and GitHub scheduling can delay completion. A failed attempt can retry after one hour, up to three recorded failures. Completed model, simulation and committee records are saved by ticker and request session under site/data/requested. Dates inside the records identify the actual data or committee run. The nightly outcome scorer evaluates eligible Qlib forecasts after the target session closes.

Qlib compares fixed ridge and ordinary least-squares models on identical held-out windows, alongside the no-change baseline. The primary model is not selected using the test results. Chronological period metrics expose instability; they are not independent forward validation.

TradingAgents CPU execution uses a bounded Qwen 2.5 1.5B model (8192 context, 384 output tokens) and two upstream analysts. The UI loads only completed records and displays the actual analyst/debate/risk text as unverified opinions. This is a resource-limited configuration, not full-capacity model inference.
